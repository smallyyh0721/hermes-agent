ProAgent 当前代码架构说明

本文档基于当前仓库中的 proagent/core、proagent/domain、 proagent/storage 与 proagent/gui 实现，说明四类 Agent 如何共享同一套运行时架构， 又如何通过 Domain Pack、Policy、Tools、Prompt 和 Storage 实现不同职责。

2. Agent 如何共享同一套架构

ProAgent 的核心设计是“一个 runtime，多种 domain pack”。四类 Agent 不各自实现一套独立框架， 而是共享 ProAgentRuntime、ProAgent、AgentRouter、 PolicyGuard 和 Phase 5 SQLite stores。

共享的运行时路径

  • AgentRouter 把入口消息映射为 agent_id 和 domain_id。
  • ProAgentRuntime 根据 domain_id 加载对应 Domain Pack。
  • DomainPack 提供 prompt、knowledge、skills、tools 和 policy。
  • ProAgent 使用同一套 LLM function calling loop 调用工具。
  • PolicyGuard 在工具调用前做权限检查，AuditStore 记录关键行为。

共享的持久化能力

  • SessionHistoryStore：记录会话、消息、工具事件。
  • WorkItemStore：记录 Develop/Test 闭环里的需求、实现、测试状态。
  • UsageStore：记录 provider 返回的 token usage。
  • SkillDraftStore：保存自动沉淀的 skill 草稿和启用状态。
  • LayeredMemoryStore：保存 user/lab/target/agent 分层记忆。

4. 请求处理流

  1. 用户通过 Discord slash command、DM、Web UI 或 CLI 发起请求。
  2. AgentRouter 解析命令，例如 /sre 检查磁盘 会映射到 server-health-inspector。
  3. ProAgentRuntime 加载对应 Domain Pack：pack.yaml、system_prompt.md、knowledge/、skills/、tools/、policy.yaml。
  4. ProAgent 组装 system prompt 和 tool schemas，调用 LLM。
  5. LLM 触发工具调用时，PolicyGuard 根据工具类别和 domain policy 决定允许或拒绝。
  6. 执行结果写入 session history、audit、usage 等 store，并返回给入口层。
  7. Web UI 从 SQLite stores 读取历史、work item、测试状态、token usage、memory 和 skill drafts。

5. Domain Pack 是职责差异的核心边界

每个 Agent 的“人格”和“能力”主要由 Domain Pack 定义，而不是由 runtime 中的 if/else 写死。 proagent/domain/base.py 的 load_pack() 会动态读取 pack 目录，并导入 tools/__init__.py 暴露的工具列表。

文件或目录 作用
pack.yaml 声明 domain id、显示名称、描述、模型偏好、入口、能力开关、最大迭代数。
system_prompt.md 定义 Agent 的职责、语气、安全规则和输出标准。
policy.yaml 定义 denylist、forbidden tools、write_action 白名单。
knowledge/ 存放领域知识、拓扑、术语、阈值、操作背景。
skills/ 存放 SOP 和可复用流程，支持后续从 skill draft 启用。
tools/__init__.py 返回该 Agent 可用的 ToolDef 列表，决定实际可执行能力。

6. 代码索引

  • proagent/core/runtime.py：共享 runtime，负责加载配置、domain pack、policy、knowledge 和 tools。
  • proagent/core/agent.py：最小 LLM loop，负责 function calling、工具执行和 token usage 记录。
  • proagent/core/agent_router.py：四 Agent 路由和 channel/thread 默认 Agent 状态。
  • proagent/domain/base.py：Domain Pack 发现与动态加载。
  • proagent/storage/phase5.py：Phase 5 共享状态库。
  • proagent/gui/app.py：Streamlit 控制台，展示历史、看板、测试状态、usage、memory、skill drafts。
  • proagent/cli/main.py：CLI、Gateway、GUI、Healthcheck 入口。
