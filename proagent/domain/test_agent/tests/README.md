# Test Agent Tests

This directory contains test cases generated by the Test Agent for validating other Domain Packs.

## Test Files

### test_aigc_image_generation.py

Tests for the AIGC Creator's image generation functionality.

**Test Categories:**

| Category | Description | Count |
|----------|-------------|-------|
| Success Paths | Basic generation, aspect ratio, styles | 4 |
| Error Handling | No API key, CLI not found, API errors, timeout, policy violation | 5 |
| Parameter Validation | Empty prompt, long prompt, special chars, multiple options | 4 |
| Command Variations | Different command formats | 1 |
| Security | API key masking, command injection prevention | 2 |
| Output Format | Success/error message format | 2 |
| Integration | Real API tests (requires MINIMAX_CN_API_KEY) | 2 |

**Running Tests:**

```bash
# Run unit tests only (no API key required)
pytest proagent/domain/test_agent/tests/test_aigc_image_generation.py -v --override-ini="addopts="

# Run with integration tests (requires MINIMAX_CN_API_KEY)
pytest proagent/domain/test_agent/tests/test_aigc_image_generation.py -v --override-ini="addopts=" --run-integration
```

**Test Design Principles:**

1. **Anti-Hallucination**: All assertions use specific expected values, not generic checks like `assert result is not None`
2. **Evidence-Based**: Each test verifies actual behavior, not predicted outcomes
3. **Security**: Tests verify API key masking and command injection prevention
4. **Mocked Unit Tests**: Unit tests mock subprocess to avoid real API calls
5. **Integration Tests**: Real API tests are separate and require credentials

## Adding New Tests

When adding tests for other Domain Packs, follow this structure:

```
test_agent/
├── tests/
│   ├── test_aigc_image_generation.py  # AIGC Creator tests
│   ├── test_server_health.py          # Server Health Inspector tests (future)
│   └── test_billing.py                # Billing tests (future)
└── README.md
```

Test naming convention: `test_<domain>_<feature>.py`
