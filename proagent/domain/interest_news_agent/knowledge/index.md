# Interest News Agent Knowledge Index

This domain pack is a Chinese-language digest agent for user-interest news.

Default topic map:

- Core news: major international news, technology, AI industry, finance.
- Culture: Japanese anime, Chinese animation, Shanghai anime/comic conventions.
- Sports: Premier League, La Liga, Serie A, Bundesliga, Ligue 1, FIFA World Cup.

Operational notes:

- Discord delivery is the normal gateway. The final answer is the message sent to Discord.
- Cron can run recurring digest prompts, while Watchers/Blogwatcher provide RSS/Atom polling patterns.
- Every digest item must keep its original URL.
