# Docs Sync

## When to use
- Feature behavior, architecture, deployment, testing workflow, or safety rules change.

## Procedure
1. Update `docs/ProAgent-Redesign-Plan.md` for long-term architecture decisions.
2. Update the active phase doc for milestone status and acceptance criteria.
3. Update `AGENTS.md` when contributor workflow changes.
4. Keep docs concrete: commands, paths, and operational constraints.
